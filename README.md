# Tic Tac Toe with Minimax Evaluation

## Overview
A strategic implementation of Tic Tac Toe featuring real-time Minimax algorithm evaluation. This wxPython-based game offers:
- Two-player (Human vs Human) gameplay
- AI-powered position evaluation visualizer
- Interactive game state analysis

## Key Features
🎮 Classic 3x3 Tic Tac Toe gameplay  
🧠 Minimax algorithm visualization  
📊 Real-time evaluation gauge  
🔄 One-click game reset  
💻 wxPython graphical interface  
🖥️ Cross-platform compatibility
